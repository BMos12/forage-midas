# Midas
My solutions for the project repo for the JPMC Advanced Software Engineering Forage program

## Overview
Midas is a Spring Boot application that processes financial transactions from Kafka, validates and persists them to an in-memory H2 database, enriches them via an external incentives API, and finally exposes a REST endpoint for querying user balances.

## Tasks
- Project Setup
- Kafka Integration
- H2 Integration
- REST API Integration
- REST API Controller
